# Vibe Creator v0.1.0-alpha

Initial public alpha release of Vibe Creator.

Vibe Creator is an open-source full-stack TypeScript workspace for AI-assisted creator-video workflows, including video editing foundations, FFmpeg-based export pipelines, background media jobs, live streaming foundations, and production-oriented SaaS architecture.

## Included

- React/Vite web application structure.
- Fastify API structure with typed validation patterns.
- PostgreSQL and Prisma database layer.
- Redis and BullMQ job processing foundation.
- FFmpeg rendering and export workflow foundation.
- Creator-video workflows: AI Director, Video Studio, Loop Creator, Reaction Recorder, Live Streaming, Trending, Workspace History, and Admin Console.
- Docker-based local infrastructure and single-node deployment references.
- Documentation, contribution guidelines, security policy, issue templates, and pull request template.

## Status

This is an early alpha release intended for development, review, and open-source collaboration. APIs, architecture, environment variables, and workflows may change before a stable release.
